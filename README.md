# Tiny Stack VM

A tiny stack virtual machine for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty. `main.ts` runs every drawn bytecode program of make.fun's tiny stack ISA and writes each one's exact output bytes and exit code.

[![make.fun bounty](https://make.fun/badge/tiny-stack-vm-01-run-20261122.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![make.fun rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/Agus12341/tiny-stack-vm/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![make.fun reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/Agus12341/tiny-stack-vm/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

Run it with `node main.ts`: instances are read from /input (or $MAKEFUN_INPUT_DIR) and answers written to /output (or $MAKEFUN_OUTPUT_DIR).
